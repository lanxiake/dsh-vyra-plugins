    § MANUAL / 04

    使用说明

    本站是多源聚合的 DeepSeek Harness 插件目录。数据在构建时从各索引源拉取、去重后生成，页面本身是静态的。

    01 /

    安装插件

    在 DSH 客户端里打开「设置 → 插件」，搜索插件名即可安装；也可以直接用命令行：

    SHELL
    dsh plugin --profile web add <包名>
    02 /

    添加索引源

    在「设置 → 插件 → 索引源」里加入下面任意一个地址。国内选 GitCode 源，海外选 GitHub 源。两份索引内容相同，仅安装源不同。

    国内 · GITCODE
    https://ghproxy.net/https://raw.githubusercontent.com/lanxiake/dsh-vyra-plugins/master/docs/index.json
    海外 · GITHUB
    https://raw.githubusercontent.com/lanxiake/dsh-vyra-plugins/master/docs/index-github.json
    ◈ 索引实时拉取，仓库更新后重新打开插件页即可看到
    03 /

    数据来源

    本站聚合 vyra / market / dshmarket / dshopen / dshtui 五个索引源。去重规则以「包名 + 仓库所有者」为键，同名 fork 不会被合并。各源条目数之和大于收录总数，正是因为跨源重复项被合并。

    DEDUP KEY
    packageName + repoOwner  →  one canonical entry
