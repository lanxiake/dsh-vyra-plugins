# 夸克网盘

## 认证（用户自己完成）

插件不内置任何账号或令牌。第一次使用前，用户需要：

1. 安装夸克网盘命令行工具（按其官方文档或 `scripts/install.sh`）
2. 执行登录，在浏览器里完成授权
3. 确认 CLI 可用（`--help` 能正常输出）

命令直接读取本机的登录配置，不要读取、输出或转述令牌内容。

## 常用操作

```bash
quark ls <目录>
quark upload <本地路径> <目标目录>
quark share <路径>
```

`share` 输出的链接和提取码就是发给买家的内容。

## 发给买家时

- 只发链接 + 提取码 + 有效期，不要出现「网盘」「云盘」「盘」这些词
- 链接失效或提取码错误：重新生成后补发

## 出错时

- 未登录：提醒用户在本机完成登录
- 空间不足 / 超出配额：告诉用户，不要自己删除已有文件
