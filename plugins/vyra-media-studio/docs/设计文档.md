## 0. 0.2.0 文件管理升级

从“媒体库”升级为“文件管理”，保留原有音视频/图片/链接能力。下面第 1–12 节记录 P0 媒体库的设计与验收，仍可作为历史背景；当前实现以本节为准。

### 0.1 文件类型

扫描不再只匹配媒体扩展名，而是收录工作区内所有普通文件，并按扩展名分类：

| 类型 | 示例 |
|---|---|
| image / video / audio | png、mp4、mp3… |
| document | pdf、docx、xlsx、pptx、md、txt、csv、epub… |
| archive | zip、rar、7z、tar、gz… |
| code | js、ts、py、go、rs、html、css、json、yaml… |
| other | 无扩展名或未知扩展名 |

类型词表位于 `lib/media-types.js`，Host 扫描、文本预览与客户端筛选共用同一套语义（客户端保留一份轻量副本，避免把 Node 依赖打进浏览器包）。

### 0.2 扫描与元数据分离

- `lib/scan.js` 使用 `fast-glob` 的 `stats:false`，只产出 `{ relativePath, name, ext, kind, folder }` 和 `folders`。
- 大小与修改时间不在扫描阶段读取，改由 `POST /api/vyra-media/stat` 批量返回（最多 200 条/次，Host 并发 32）。
- 客户端只在以下场景请求元数据：网格/列表的可见页；列表“详细”模式；按时间/大小排序或筛选。
- Host 扫描结果有 15 秒 TTL 缓存与 in-flight 去重；任何写操作和手动刷新都会清空缓存。

### 0.3 视图

- 网格：`--vms-card-min` CSS 变量控制 `auto-fill/minmax`，滑杆与 Ctrl+滚轮实时缩放，尺寸持久化到 `localStorage`。
- 列表：`compact`（名称 + 路径）与 `detailed`（再加修改日期、类型、大小）两档。
- 文件夹：面包屑 + 文件夹弹层；还有“显示隐藏文件”和“包含依赖/构建目录”两个慢速开关。

### 0.4 文件操作

新增 `lib/file-ops.js` 与以下 Host 路由：

| 路由 | 作用 |
|---|---|
| `POST /stat` | 批量 size/mtime/绝对路径 |
| `GET /text` | UTF-8 文本窗口，用于文本预览与文本缩略图（上限 1 MiB） |
| `POST /rename` | 同目录重命名 |
| `POST /copy` | 复制到工作区目标文件夹，重名自动 `name (2).ext` |
| `POST /delete` | 系统回收站；失败时才允许永久删除 |
| `POST /reveal` | `explorer /select`、`open -R`、`xdg-open` |
| `POST /open` | 用系统默认应用打开 |

所有路径先经 `workspaceFiles.scopeOf` → `ctx.fs.resolve` → `ctx.fs.contains`；写操作使用 Host 进程文件系统以支持二进制文件，因此限本地后端。远程 SSH 后端不做写操作。

### 0.5 预览与缩略图

- 文本类文档：懒加载前 600 字节作为真实内容缩略图；预览时最多读取 1 MiB。
- PDF：面板内 `<iframe>` 调用浏览器 PDF 阅读器。
- Office/压缩包/未知类型：按扩展名着色的图标缩略图 + “用系统应用打开”。
- 灯箱、列表行、预览头部共用同一套操作菜单：引用到输入框、复制到…、复制地址、重命名、打开所在位置、系统打开、删除。

### 0.6 引用到输入框

`src/client/composer.js` 注册 `conversation.input.left` slot，按 Session 捕获 composer 的 `inputActions`；面板调用 `insertComposerText` 插入 `@相对路径 `（含空格时加引号）。

## 1. 背景与目标

DSH 的右侧栏已经具备完整的 tab、分屏、浮动和持久化能力，文件树、工作区搜索、资源地址、图片/PDF/Office 预览也可复用。但视频和音频没有查看器，`mp4`、`mp3` 等文件在文档预览里会落到“无法预览”；现有 `/api/file` 只做整文件读取，没有 Range，不能支撑大视频的拖动和流式播放。

本插件解决三件事：

1. **本地音视频可播**：在右侧栏打开视频/音频，不整文件进内存，支持拖动进度。
2. **媒体库可浏览**：递归扫描当前工作区，卡片式网格/列表浏览，多条件筛选、搜索、排序。
3. **在线直链可播**：P0 支持直接媒体 URL；普通网页链接交给现有 Browser tab。

### 1.1 已确认的产品决策

| 决策 | 结论 |
|---|---|
| 平台 | Web + Desktop 双端 |
| 媒体库范围 | 默认递归扫描整个工作区，支持文件夹过滤 |
| 查询 | 名称、类型、时间、大小、文件夹多条件组合；支持排序 |
| 在线内容 | P0 只支持直接媒体 URL；资源嗅探放 P1，目标是让在线播放和本地一样干净、少干扰 |
| 图片预览 | 与 DSH 原生图片预览共存；媒体库提供轻量放大查看，复杂查看仍可“在标签页打开” |
| 缩略图 | P0 用浏览器懒加载首帧；不引入 ffmpeg / 服务端缩略图 |
| 拖入本地文件 | P1 |
| 远程工作区 | P0 只保证本地文件系统 |
| 插件名 | `vyra-media-studio` |

### 1.2 P0 非目标

- 视频转码、代理、格式转换
- 波形图、逐帧缩略图带、字幕轨
- 网页 OG 抓取、资源嗅探、B 站/YouTube 嵌入
- SSH / 远程文件系统的媒体预览
- 收藏、标签、批量导出、批量重命名

## 2. 用户体验

### 2.1 入口

1. **右侧栏 guide** 新增“媒体库”卡片，点击打开 `media` page tab。
2. **文件树**里的音视频文件变为可点击：注册 `video` / `audio` extension 类型，点击后打开对应预览 tab。
3. 媒体库卡片点击 → 面板内放大查看；卡片上的“在标签页打开” → 打开独立预览 tab。
4. 普通网页链接 → 交给 Browser tab；Web 下 Browser 未启用时回退到系统浏览器。

### 2.2 媒体库布局

```
┌──────────────────────────────────────────────┐
│ 媒体库   12 个媒体    [网格|列表]  [刷新]      │
│ [搜索…] [全部|视频|图片|音频|链接]            │
│ [文件夹▾] [时间▾] [大小▾] [排序▾] [方向]      │
│ 筛选：7 个结果   [清除]                       │
├──────────────────────────────────────────────┤
│ ┌──────┐ ┌──────┐ ┌──────┐                   │
│ │ 01   │ │ 02   │ │ 03   │                   │
│ │ 视频 │ │ 图片 │ │ 音频 │                   │
│ └──────┘ └──────┘ └──────┘                   │
├──────────────────────────────────────────────┤
│ 已扫描 34 个目录 · 跳过 3.2k 个构建目录       │
└──────────────────────────────────────────────┘
```

顶部只保留高频操作，不堆工具栏。扫描状态放在底部一行，失败/截断提示也在这里，不弹窗打断浏览。

### 2.3 卡片

**视频卡**

- 16:9 首帧/海报，左上角 `01` 序号，右上角“视频”类型，右下角时长
- 悬停显示中央播放按钮；点击播放按钮 → 卡片内原地播放
- 点击卡片其他区域 → 打开放大 overlay
- 卡片底部：文件名、文件夹、大小、修改时间
- 播放中：卡片内换成浏览器原生 `<video controls>`，保留标题与元数据

**图片卡**

- 懒加载缩略图，保持原始构图；点击 → 图片 overlay
- overlay 支持缩放、适应窗口、100%、拖动查看
- “在标签页打开”继续使用 DSH 原生图片预览

**音频卡**

- 封面占位（按文件哈希取色）+ 静态波形纹理
- 播放按钮 → 卡片内展开原生 `<audio controls>` 播放器
- 播放中切到其他 tab 继续播放（预览 tab 使用 `keepMounted`）

**链接卡**

- 直接媒体 URL（mp4/webm/mp3/wav 等）：按视频/音频卡处理，直接播放
- 普通网页：显示域名、标题、类型；点击 → Browser tab
- P0 不抓取网页标题和图片，避免网络请求、隐私和 SSRF 问题

### 2.4 原地播放规则

- 同一时间只有一个卡片在播放；开始新卡片时暂停上一个。
- 筛选、排序、切换视图、切换会话时暂停并清空原地播放器，避免元素在 DOM 重建后变成孤儿。
- 视频在右侧栏 tab 不可见时暂停；音频可继续播放。
- 关闭预览 tab 时停止音频。

### 2.5 放大 overlay

用于面板内灯箱的成熟开源组件 [`yet-another-react-lightbox`](https://github.com/igordanchenko/yet-another-react-lightbox)（MIT）：

- `Inline` 插件把灯箱渲染在当前右侧栏面板内，不弹到全屏窗口。
- `Video` 插件负责视频 slide，使用浏览器原生 `<video controls>`。
- `Zoom` 插件负责图片滚轮缩放、拖动平移，`Thumbnails` 负责底部缩略图条，`Counter` 显示序号，`Fullscreen` 提供全屏。
- 音频与网页链接是自定义 slide：音频用原生 `<audio controls>` + 封面/波形，链接显示域名、完整 URL、复制链接与在浏览器打开。
- 顶部保留插件自己的标题栏：文件名、文件夹、类型、大小、移除链接、在标签页打开/新窗口播放、下载、关闭。
- 键盘：`Esc` 关闭；`←`/`→` 上一个/下一个由灯箱处理；视频播放/暂停、进度、音量、全屏、画中画由原生控件处理。

### 2.6 状态

| 状态 | 呈现 |
|---|---|
| 首次扫描 | 骨架卡片 + “正在扫描工作区…” |
| 空工作区 | 说明 + 刷新 + “拖入文件（P1 提供）” |
| 无匹配 | 当前筛选条件摘要 + 清除筛选 |
| 扫描截断 | 底部提示“媒体文件过多，仅显示前 N 个” |
| 文件不可读 | 卡片上显示原因 + 重试 |
| 编码不支持 | overlay 显示“当前浏览器无法播放此编码”，提供“用系统应用打开” |
| 在线链接失败 | overlay 显示网络/防盗链提示，保留原链接可复制 |

## 3. 数据模型

```ts
type MediaKind = 'video' | 'image' | 'audio' | 'link'
type LocalMediaKind = Exclude<MediaKind, 'link'>

interface MediaItem {
  id: string                 // 本地：relativePath；在线：url
  kind: MediaKind
  title: string              // 文件名或链接标题
  fileName: string
  folder: string             // 相对工作区目录，根目录为 ''
  relativePath: string       // 本地媒体
  size?: number              // bytes
  mtimeMs?: number           // 修改时间
  duration?: number          // 秒，播放后回填
  width?: number
  height?: number
  source: 'local' | 'url'
  url?: string               // 在线直链
  ext: string
}
```

### 3.1 类型来源

- 本地扫描：Host 的 `/api/vyra-media/list` 返回 `video|image|audio`。
- 在线链接：客户端 localStorage 持久化，按工作区根目录分桶。
- 时间、大小、文件夹、名称都来自扫描结果或链接创建时间；不依赖模型或 Session 事件。

### 3.2 多条件筛选

所有条件之间是 **AND**，同一条件内（如类型多选）是 **OR**：

| 条件 | 语义 |
|---|---|
| `query` | 不区分大小写，匹配文件名、相对路径、文件夹、链接标题/域名 |
| `type` | `all` 或 `video/image/audio/link` 多选 |
| `folder` | 目录前缀精确匹配；`''` 表示全部 |
| `time` | `all / today / 7d / 30d`，基于 `mtimeMs` 或链接创建时间 |
| `size` | `all / small(<10MB) / medium(10–100MB) / large(>100MB)` |
| `sort` | `name / time / size / type`，默认 `time desc` |
| `direction` | `asc / desc` |

排序规则：

- 名称：自然排序，数字按数值比较，忽略大小写。
- 时间：`mtimeMs` 降序默认。
- 大小：无 `size` 的链接排最后。
- 类型：视频 → 图片 → 音频 → 链接，然后按名称。

筛选/排序/视图偏好保存在 tab 的 store，随 tab 布局持久化；链接列表按工作区根目录存 localStorage。

                                       │ Cookie / Desktop 私有 Cookie
┌──────────────────────────────────────┴───────────────────────────────────────────┐

### 4.1 Host 半

插件入口 `index.js`，`inject: ['fs', 'workspaceFiles']`，再在 `connection` 就绪后注册两条 exact Fetch 路由。

#### `GET /api/vyra-media/list`

查询参数：

| 参数 | 默认 | 说明 |
|---|---|---|
| `sessionId` | 必填 | 用于解析工作区根 |
| `root` | `''` | 相对工作区根的扫描起点；也可传工作区内绝对路径 |
| `maxEntries` | `3000` | 媒体条目上限 |
| `maxDepth` | `8` | 最大递归深度 |
| `includeHidden` | `false` | 是否包含点文件/点目录 |

响应：

```json
{
  "root": "/workspace/demo",
  "entries": [
    {
      "relativePath": "作品/开箱/opening.mp4",
      "name": "opening.mp4",
      "kind": "video",
      "ext": "mp4",
      "size": 512000000,
      "mtimeMs": 1764000000000
    }
  ],
  "scannedDirectories": 34,
  "skippedEntries": 0,
  "truncated": false
}
```

实现规则：

- 用 `workspaceFiles.scopeOf(sessionId)` 解析工作区根；拒绝 `root` 越界（规范化后必须在根内）。
- 用 [`fast-glob`](https://github.com/mrmlnc/fast-glob)（MIT）以流式方式遍历；不跟随 symlink，大小写不敏感。
- 默认跳过：`.git`、`.hg`、`.svn`、`node_modules`、`dist`、`build`、`coverage`、`.next`、`.turbo`、`.pnpm-store`、`.yarn`、`vendor`、`.DS_Store`。
- 只收集配置的媒体扩展；目录/其他文件不返回。
- 达到 `maxEntries` 或超过预算（默认 12s）时停止流，返回 `truncated: true`。
- `scannedDirectories` 是包含媒体的目录数；`skippedEntries` 由 glob 的 ignore 规则处理，P0 固定为 0。
- 响应 `Cache-Control: private, no-store`。

> P0 本地优先：Node fs 只读取 Host 本机文件。远程工作区后续改为走 `ctx.fs` 或 workspace-files 的扫描服务。

#### `GET /api/vyra-media/file`

查询参数：

| 参数 | 必填 | 说明 |
|---|---|---|
| `sessionId` | 是 | 授权会话 |
| `path` | 是 | 工作区内相对路径，或工作区内绝对路径 |
| `v` | 否 | 文件版本；用于 ETag/条件请求，不是缓存键的唯一依据 |

响应头：

- `Content-Type`：按扩展名映射；未知为 `application/octet-stream`
- `Accept-Ranges: bytes`
- `ETag: "<version>"`
- `Cache-Control: private, max-age=0, must-revalidate`
- `X-Content-Type-Options: nosniff`
- `Content-Security-Policy: sandbox; default-src 'none'`

状态：

| 场景 | 响应 |
|---|---|
| 完整读取 | `200` + `Content-Length` |
| 单段 Range | `206` + `Content-Range` + `Content-Length` |
| 非法/越界 Range | `416` + `Content-Range: bytes */<size>` |
| HEAD | 与 GET 相同头，无 body |
| 路径越界/符号链接 | `403` |
| 文件不存在 | `404` |
| 超过大小上限 | `413` |

Range 规则：

- 只支持单段 `bytes=start-end`、`bytes=start-`、`bytes=-suffix`。
- 多段 Range 不解析，按完整 `200` 返回（浏览器会自行处理）。
- `If-Range` 与当前 ETag 不匹配 → `200` 完整内容。
- `start >= size` → `416`。
- 分块读取，块大小 1 MiB；每块通过 `fs.readByteRange` 获取，写入 `ReadableStream`，遵循背压。
- 请求中止 → 停止读取、取消流。

### 4.2 Client 半

插件 `client.js` 由 esbuild 打包，再套一层 `window.__ModuleLoader__.load({ id, factory(require) })`：React/ReactDOM 从平台模块表取，灯箱与 lucide 图标打进 bundle。源码在 `src/client/`，改完执行 `pnpm run build:client`。

注册：

1. `sidebarRightTabs.register({ id: 'vyra-media-studio/library', kind: 'media', priority: 'extension', title, guide: [...] })`
2. `sidebar.right.pane.tab` 的 keyed body：媒体库页面。
3. `sidebarRightTabs.register({ id: 'vyra-media-studio/video', kind: 'video', patterns: ['*.mp4', ...], priority: 'extension', title, keepMounted: true })` + body。
4. `sidebarRightTabs.register({ id: 'vyra-media-studio/audio', kind: 'audio', patterns: ['*.mp3', ...], priority: 'extension', title, keepMounted: true })` + body。
5. 页面/媒体 tab 的标题由类型定义的 `title(address)` 提供；不额外注册 title 组合。

依赖注入：`slots`、`sidebarRightTabs`、`sidebarRight`。工作区根由 Host 通过 `workspaceFiles.scopeOf(sessionId)` 解析，客户端只传 `sessionId`，不猜 cwd。

### 4.3 资源地址与 URL

- 文件树打开地址：`dsh-resource://file/session/<sessionId>/<encoded path>`。
- 媒体 tab body 从 `useTabInfo().tab.contentId` 解析 `sessionId` 与相对路径，避免客户端猜 Session。
- 工作区根：客户端不读取 cwd；`/api/vyra-media/list` 与 `/api/vyra-media/file` 都在 Host 用 `workspaceFiles.scopeOf(sessionId)` 解析并做 `ctx.fs.contains` 越界检查。
- 媒体 URL：

```ts
const url = new URL('api/vyra-media/file', document.baseURI)
url.searchParams.set('sessionId', sessionId)
url.searchParams.set('path', relativePath)
if (version) url.searchParams.set('v', version)
```

Desktop 下 `document.baseURI` 是 `dsh-app://app/`，请求由主进程转发到 Host 并带私有 Cookie；Range 请求头会一并转发。

### 4.4 图片策略

- 媒体库卡片使用 `/api/vyra-media/file` 的图片 URL 或原文件 URL 懒加载。
- 点击“在标签页打开”打开 `dsh-resource://file/...`，由 DSH 原生 `text` 类型中的图片 renderer 处理；本插件不注册图片扩展，避免抢走现有体验。
- 媒体库灯箱使用 lightbox 的 `Zoom` 插件做轻量查看；拖拽/原生文件动作仍由 DSH 图片预览负责。

### 4.5 开源复用

| 依赖 | 用途 | 许可 |

播放控制使用浏览器原生 `<video controls>` / `<audio controls>`；插件只保留产品自己的媒体库、筛选、卡片与 host 路由。客户端由 esbuild 打包成单个 `client.js`，React/ReactDOM 仍由 DSH 模块表提供。完整许可见 [`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md)。

## 5. 扫描与性能

- 首次打开媒体库时请求一次 list；返回后客户端完成筛选/排序，后续交互不再请求。
- 扫描上限：3000 个媒体条目、8 层深度、15s；超限返回 `truncated`。
- 默认跳过构建目录和隐藏目录，避免 `node_modules` 拖慢。
- 目录扫描在 Host 端用 `fast-glob` 流式完成，客户端只渲染结果；不逐目录发 Remote 请求。
- 手动刷新按钮重新扫描；P0 不监听文件变化。
- 网格缩略图：
  - 图片：`loading="lazy"` + `decoding="async"`。
  - 视频：`IntersectionObserver` 挂载 `<video preload="metadata" muted playsinline>` 取首帧；灯箱缩略图也用同样的首帧方案。
  - 音频：封面由文件名哈希生成，不加载媒体。
- 列表模式只为可视行加载缩略图。
- 原地播放与 overlay 各只保留一个媒体元素；离开时销毁。

## 6. 安全

- 两条 Host 路由默认 `auth: required`，沿用 DSH 的来源校验与 Cookie。
- `list` 和 `file` 都以 `sessionId` 解析工作区根，拒绝根外路径；`..` 规范化后再次校验。
- 不跟随最终 symlink；不读取目录、设备文件或其他非普通文件。
- 只返回普通文件字节，不解释 HTML/SVG 为可执行页面；统一 `nosniff` 与 CSP。
- P0 不代理在线 URL，不做服务端抓取，避免 SSRF。
- 在线直链由浏览器直接加载；防盗链/CORS 失败只在 UI 提示，不绕限制。
- 不把完整路径写入日志；错误日志只记录会话 ID、相对路径和错误码。

## 7. Web / Desktop 差异

| 项 | Web | Desktop |
|---|---|---|
| 媒体 URL | 相对 `api/vyra-media/...` | `dsh-app://app/api/vyra-media/...`，主进程带 Cookie 转发 |
| Range | 原生支持 | 主进程转发 Range，需实测 206 与流式 body；转发会移除 `content-length` |
| 网页链接 | Browser tab 默认关闭时回退系统浏览器 | Browser webview 可直接打开 |
| 全屏 | Fullscreen API | Fullscreen API |
| 系统应用打开 | `ui-open-in-app` 可用时可用 | 可用 |

**首要风险**：Desktop 的 `forwardWebRequest` 会删除 `content-length` 和 `content-encoding`，但保留 `content-range`/`accept-ranges`。若 Chromium 媒体栈不接受，需要改用 `net.fetch`/自定义流式响应，或在允许范围内调整转发策略。实现第一步必须用 Desktop 实测 206 + 拖动。

## 8. 编码支持

| 类型 | P0 支持 | 说明 |
|---|---|---|
| 视频 | mp4 (H.264/AAC), webm (VP9/Opus), mov/m4v (H.264), ogv | HEVC/AV1 取决于浏览器；mkv/avi 通常不可播 |
| 音频 | mp3, wav, m4a/aac, flac, ogg/opus | 以浏览器实测为准 |
| 图片 | png, jpg/jpeg, gif, webp, bmp, ico, svg | 仅媒体库展示；预览交给原生图片 renderer |

不可播时：保留卡片/文件名，显示“当前浏览器不支持此编码”，并提供“用系统应用打开”（若 `ui-open-in-app` 可用）或“复制路径”。
