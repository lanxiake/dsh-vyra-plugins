# 免费模型（Vyra Free Model）

装上就能用的免费模型。不用注册、不用填 key、不用懂「渠道」「适配器」这些词——
**三步以内就能开始聊天。**

---

## 三步上手

### 第一步：装上

在 DSH 的插件市场里搜索「免费模型」，点安装，重载 Web 界面。

装好后，模型选择器里会多出一组 **免费模型**，默认已经选中
**自动选择（推荐）**。到这里就可以开始聊天了 —— 后面两步都是可选的。

### 第二步（可选）：登录一个国内账号，换更多额度

设置 → 免费模型 → 「账号」这一块。

六家国内产品各有一个「登录」按钮：Qoder 中国版、TRAE、ZCode、MiniMax、
有道 LobsterAI、讯飞 Loomy。点一下，浏览器会打开授权页，登录完成后回到这里，
卡片会自己变成「已登录」并显示积分。

> 不登录也能用上面的免费模型。登录只是多一份额度。
> 积分每天会**自动领取**一次，成功不打扰你；万一没成功，卡片上会出现一行提示和一个「重试」。

第七家「商汤 Raccoon」折在「更多」里 —— 用的人少，不占视线。

### 第三步（可选）：让 Cursor / Claude Code 也用上

设置 → 免费模型 → 「让别的工具也用上」，打开开关。

它会显示一个本地地址（形如 `http://127.0.0.1:8899/v1`）和一个密钥，
下面两个按钮分别给出 **Cursor** 和 **Claude Code** 需要的配置，点「复制」粘过去就行。

这个地址**只在你本机有效**，关掉开关立刻就停。

## 界面长什么样

设置页只有三块，从上到下就是上面三步的顺序：

| 块 | 你在这里做什么 |
| --- | --- |
| **模型** | 选一个模型，或者留着「自动选择」。右上角「重新检测」可以随时刷新列表 |
| **账号（可选）** | 想多一份额度时，登录一个国内账号 |
| **让别的工具也用上（可选）** | 想让 Cursor / Claude Code 共用这批模型时打开 |

页面右上角还有一个开关，可以把整组模型从选择器里关掉（也能随时打开）。

## 已知限制

说清楚比说好听重要。以下六条都是真实存在的行为，不是待修 bug：

1. **免费池是上游的，不是我们的。** 这些模型由第三方免费池提供，上游随时可能调整、
   限流或下线某一个。某一个突然不可用，通常等一会儿或换个模型就好。
2. **提示词可能被上游记录。** 免费池通常会把请求记进日志用于改进服务。
   **别在免费模型里发敏感内容** —— 密码、身份证、公司内部资料都不合适。
3. **免费额度有上限。** 每个模型有各自的免费配额，用完会提示额度耗尽。
   这不是故障，等一段时间恢复，或者登录账号换取更多。
4. **积分是各家自己的。** 登录账号后拿到的积分属于对应产品，规则、有效期、能否叠加
   都由那家决定。本插件只负责帮你领取，不保证领得到。
5. **转发端口只在本机。** 它绑定 `127.0.0.1`，局域网里的其他设备连不上 —— 这是故意的，
   否则你一个人的免费额度会变成整层楼共用的。
6. **不能保证一直可用。** 上游接口、授权流程、页面结构都可能变。真出问题时，
   设置页会给你一句人话和「重试」，而不是一个空白页。
