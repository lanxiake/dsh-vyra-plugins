# 免费模型（Vyra Free Model）

装上就能用的免费模型。不用注册、不用填 key、不用懂「渠道」「适配器」这些词——
**两步以内就能开始聊天。**

---

## 两步上手

### 第一步：装上

在 DSH 的插件市场里搜索「免费模型」，点安装，重载 Web 界面。

装好后，模型选择器里会多出一组 **免费模型**，默认已经选中
**自动选择（推荐）**。到这里就可以开始聊天了 —— 后面的账号与自带 Key 都是可选的。

### 第二步（可选）：登录一个国内账号，换更多额度

设置 → 免费模型 → 「账号」这一块。

每家产品各有一个「登录」按钮：Qoder 中国版、Qoder 国际版、TRAE、ZCode、
MiniMax、有道 LobsterAI、讯飞 Loomy、Cline。「商汤 Raccoon」折在「更多」里。

点一下，**系统浏览器会直接打开授权页**，同时弹出一个 **登录授权弹窗**：
里面是完整授权链接，可一键打开、可复制、可选中。浏览器没自动弹出来时，
把这个链接复制到任意浏览器里就能完成授权。

登录完成后卡片会变成「已登录」，账号昵称、余额和今天是否已领取都会显示出来。

**多账号**：每个产品都可以登录多个账号，点「添加账号」再登录一次即可。
每个账号单独一行，支持 **停用 / 启用 / 删除**；停用只影响自动选号，凭据仍保留。删除后列表立即刷新。

**不会重复登录同一个账号**：登录完成后会按凭据里的用户 id / 手机号 / 邮箱 / 昵称判断，如果这个账号已经在列表里，新的重复记录会被自动移除，并提示「这个账号已经登录过了」。
「刷新积分」会查询所有账号的余额；「重新领取」按产品领取今日积分。

**CodeBuddy / WorkBuddy 也在同一份账号列表里**，和 Qoder、TRAE 等渠道并排，
一样支持多账号、余额与每日领取，登录后它们的模型会并入上面的「免费模型」组。

> 不登录也能用上面的免费模型。登录只是多一份额度。
> 积分每天会**按产品逐个自动领取**一次，成功不打扰你；没成功时卡片上会出现提示和「重试」。

Google 的 Gemini 没有列出来：这台机器访问不到 `accounts.google.com`，放一个
永远完不成的登录按钮比不放更糟。

### 第二步之二（可选）：CodeBuddy / WorkBuddy

它们就在上面「账号」列表的最后两行。登录腾讯账号后，模型会并入「免费模型」组，
和 Kilo 的模型一起出现在选择器里；账号管理与积分也和其他渠道一致。

- 协议来自 MIT 的 `dsh-codebuddy` 项目，登录走官方 IDE 插件端点
- 腾讯会拦截 DSH 原文提示词，插件会在发请求前把 system 和历史里已知的触发句
  换成中性文案
- 账号令牌保存在 `~/.dsh/dsh-vyra-free-model/buddy.json`（0600），只在本机

### 第二步之三（可选）：自带 Key 的模型

「自带 Key 的模型」卡片支持任何 OpenAI 兼容接口，内置豆包（火山方舟）、Kimi、
智谱、SiliconFlow、DeepSeek 的地址预设。填入 Base URL 和 Key，点「检测模型」，
它的模型就会并入同一个「免费模型」组。

- **豆包没有匿名免费接口**，它的免费额度和账号绑定在火山方舟的 API Key 上
- Key 只保存在 `~/.dsh/dsh-vyra-free-model/settings.json`（0600），接口只回传
  「是否已保存」，从不回传 Key 本身
- 留空 Key 保存时表示保持原来的 Key 不变

## 更多插件与 DSH 使用指南

装上本插件时，宿主会顺手做两件事：

1. **安装 `vyra-dsh-guide` 技能**：写到 `~/.dsh/skills/vyra-dsh-guide/SKILL.md`。
   之后你问 Agent「DSH 怎么用」「该装什么插件」「帮我配一套工作台」时，
   它会先了解你的场景，再推荐 2–3 档插件组合，并优先检索 Veyra 源。
2. **设置页底部多一张「还想要更多」卡片**：点「一键安装插件市场」会
   - 把 Veyra 插件源加入「设置 → 插件 → 索引源」（已加则跳过）；
   - 没装过 `dsh-vyra-plugin-market` 就装上，装完重启 DSH 就能在左侧栏或插件页打开；
   - **已经装过**则把按钮换成「更新插件市场」，通过宿主的 `updateBundle` 把它更新到
     索引里的最新版本，并显示 `v旧 → v新`；没有新版本时提示「已是最新版本」。

卡片里还有四句 DSH 使用提示：直接说目标、不知道做什么就问 Agent 要推荐、
插件装完要重启、这里装的市场和「设置 → 插件」里的是同一个。
安装或更新失败时卡片会给出宿主返回的原因，并指向「设置 → 插件」手动处理。

3. **页面标题行右侧固定着「QQ 交流群」和「GitHub」两个入口**，和标题同一行、
   靠右对齐，不用翻到页面底部。点 QQ 打开二维码浮层（扫一扫加群，也能直接复制群号
   1121362543）。二维码由插件自己的路由 `/api/dsh-vyra-free-model/assets/qq-group.png`
   提供，不依赖外网图床，也不塞进页面里当 base64。

这两个入口用的就是页面里「刷新积分」「添加账号」同一种按钮（同样的尺寸、圆角、
文字颜色和悬停效果），全页只有一套按钮语言。

> 配色全部取自宿主的主题变量（背景色与文字色成对使用），
> 浅色、深色以及「自由主题」这类自定义主题下都能看清，悬停不会让文字消失。

## 界面长什么样

设置页从上到下：

| 块 | 你在这里做什么 |
| --- | --- |
| **标题行** | 左边是页面标题；右边靠右对齐「QQ 交流群」「GitHub」两个入口和总开关 |
| **模型** | 看模型清单与可用状态；右上角「重新检测」会对每个模型发一次真实请求 |
| **账号（可选）** | 登录国内账号（含 CodeBuddy / WorkBuddy），管理多个账号、余额与每日领取 |
| **自带 Key 的模型（可选）** | 豆包、Kimi、智谱、SiliconFlow 等 OpenAI 兼容接口 |
| **还想要更多** | 一键安装插件市场（已装则一键更新）、添加 Veyra 插件源，附 DSH 使用提示 |

这些块**默认都是收起的**，页面上先看到三行摘要；点标题展开。页面底部还有一张
常驻的「还想要更多」卡片，用来一键安装插件市场和查看 DSH 使用提示。页面右上角还有一个开关，可以把整组模型从选择器里关掉（也能随时打开）。

模型来源写在「模型」块里：Kilo AI 公共免费网关（kilo.ai），`isFree` 清单实时
拉取，每行带厂商标签。

**可用性状态**：点「重新检测」后，每个模型会得到 可用 / 限流 / 不可用 / 未确认 之一
（1 token 的真实请求，12 秒超时）。**不可用**（404 / 模型被上游明确下架）的模型
不再出现在选择器里；限流、超时、5xx 只标注状态，不剔除——一次临时故障不该把
模型藏起来。

**自动选择**：第一轮对话结束后，模型选择器和设置页会显示实际路由到的模型名、
上下文长度和是否支持图片。

**自动切换模型**（默认开启）：自动选择被上游拒绝（限流、额度用完、5xx、连不上）
且**还没有输出任何正文**时，插件会换下一个可用模型重试，最多试 3 个；只有全部
失败才把错误给你。已经输出正文后不会切换，避免屏幕上出现重复内容。
设置页「模型」块底部可以关闭这个开关。

## 已知限制

说清楚比说好听重要。以下七条都是真实存在的行为，不是待修 bug：

1. **免费池是上游的，不是我们的。** 这些模型由第三方免费池提供，上游随时可能调整、
   限流或下线某一个。某一个突然不可用，通常等一会儿或换个模型就好。
2. **提示词可能被上游记录。** 免费池通常会把请求记进日志用于改进服务。
   **别在免费模型里发敏感内容** —— 密码、身份证、公司内部资料都不合适。
3. **免费额度有上限。** 每个模型有各自的免费配额，用完会提示额度耗尽。
   这不是故障，等一段时间恢复，或者登录账号换取更多。
4. **积分是各家自己的。** 登录账号后拿到的积分属于对应产品，规则、有效期、能否叠加
   都由那家决定。本插件只负责帮你领取，不保证领得到。
5. **不能保证一直可用。** 上游接口、授权流程、页面结构都可能变。真出问题时，
   设置页会给你一句人话和「重试」，而不是一个空白页。
6. **腾讯账号协议是逆向实现。** CodeBuddy / WorkBuddy 的提示词指纹拦截规则可能
   随时增加；届时需要更新内置的中性文案。失败时会如实报错，不会静默重试。
7. **自带 Key 的端点由你自己负责。** 豆包等服务的免费额度、计费和条款归对应
   厂商，本插件只负责转发请求，不代管、不退款。
