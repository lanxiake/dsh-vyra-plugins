# 开机决斗

打开 DSH Web 界面（刷新或新开标签页）时，首页会被一层全屏**水墨武侠决斗**盖住：竹林与远山做背景，左右两条血条与一条气槽，底部是中文操作说明，右下角是跳过按钮。先按 `Enter` 起势，把对手（右侧品红火柴人）的血条打空就 KO，之后自动淡出进入首页。

## 开始与节奏

打开界面先是**对峙**：两人在竹林里呼吸对视，血条与气槽备好，中间是「开始 Enter」提示。**按 Enter（或点「开始」）才开打** —— 在这之前谁也伤不到谁，你可以先看清操作说明再出手。

## 操作

| 输入 | 动作 | 说明 |
| --- | --- | --- |
| `A` / `D` 或 `←` / `→` | 移动 | 场边有限制 |
| `J` | 直拳 | 前摇 4 帧、判定 3 帧、收招 7 帧，伤害 8 |
| `J` + `S` | 上勾拳 | 下蹲蓄力后向上爆发，把对手打浮空，是连招的起手 |
| `K` | 踢击 | 前摇 8 帧、判定 4 帧、收招 12 帧，伤害 14，距离更远、破绽更大 |
| `K` + `S` | 扫腿 | 低位扫踢，对手失衡；低段攻击破格挡 |
| `K` + 朝向对手 | 滑铲 | 贴着地面突进的低段攻击 |
| `L`（按住） | 格挡 | 减伤 80%，被踢仍会被小幅击退 |
| `空格` / `W` | 跳跃 | 滞空 24 帧，空中可以出拳 |
| `U` 或 `I` | 大招「破军」 | 需气槽满；伤害 30，长蓄力会被打断 |
| `Esc` 或右下角「跳过」按钮 | 跳过 | 一次即可跳过整局，同样正常进入首页 |

**两个攻击键 + 一个方向，就是全部招式。** 前作的六个攻击键把操作区做成了键盘说明书；现在 `J`/`K` 配上下/朝向就覆盖六招，界面上的按键提示也只列这些。旧布局的 `H`/`G`/`F`/`N` 仍然可用，只是不再宣传。

## 连招

命中会打开一个约 0.55 秒的取消窗口（按实时时间算，大约 250ms 以上能摸到）。窗口里：
- 再次按 `J` 会在直拳/摆拳之间交替，串成一串；
- 任何一段都能被 `K`、`J+S` 等招式**取消**——踢完接上勾是成立的；
- 连段中的对手会被「钉住」在攻击范围内（最多 4 段），最后一击才把人打飞。

所以连招不是「连续命中」，而是「上一击还没恢复就接下一击」。乱按也能出 3～4 段，但读招式的人能接得更长、伤害更高。

每个动作都有前摇、判定、收招三段，命中后还会额外收招——所以**乱按不如抓时机**：连续挥拳的命中率很低，等对手出招收招的空档再出手更划算。

## 过关条件

只有一条：对手血量归零。双方各 100 点，不设时间限制，也没有多回合。

**玩家不会被判定失败。** 你的血量最低保留 1 点（并出现残血红屏），所以那一局一定能打完，不存在"开机被卡住"的情况。这是刻意的设计取舍：代价是这局没有真正的输赢压力。

## 气与大招

每次干净命中都会积「气」，被打中也会积一点（翻盘阀）。气满时血条下方会亮起提示，此时按 `U` 放出「破军」：

- 五个节拍：蓄力（工位上的键鼠杯椅被吸到拳前悬停）→ 报招名 → 放招（键盘、杯子、显示器依次砸出）→ 命中（椅子抡上去、「已驳回」工单章盖下、碎片炸开）→ 收势；
- 椅子落下的瞬间才是真正结算的一次重击，伤害走和普通招式同一条路径；
- 命中瞬间：定格、慢动作、镜头震、墨轮爆开、速度线、盖印。

简单难度下，气满之前一局通常已经打完，所以大招是给「打得规整」的人的奖励，不是必须的通关手段。

## 默认行为

- **默认静音。** 音效优先用插件自带的 CC0 录音（Kenney 的打击 / 金属 / 衣料），路由不可用时回落到 WebAudio 合成；起势时还会播放一段 CC0 战斗音乐（Beatscribe 的 `boss_appears`），一局一遍、不循环，点静音按钮会开启音效，状态只存在内存里。
- **默认简单难度**，每局开局重来，不做持久化——刷新页面就会再看一次开场。
- 系统开启了「减少动态效果」时：命中定格缩短、不抖屏不闪白，KO 慢动作降到 0.5×，大招的推镜也减弱。
- 游戏层用 `window` 捕获阶段监听键盘，所以**不用先点一下画面**就能玩；焦点落在输入框、可编辑区域或宿主的其他模态框上时，按键完整交给它们，不会被游戏吞掉。结束时焦点回到挂载前的位置。
- `Esc` 在任何阶段都生效（对局中、KO 演出中、连按多次），右下角还有一个鼠标可点的「跳过」按钮，所以不存在"卡在动画里出不去"的状态。

## 配置

在「插件」页该插件的配置里改，或直接改 `cordis.patch.yml`：

```yaml
- insert:
    - id: boot-duel
      name: dsh-boot-duel
      config:
        enabled: true    # 改成 false 即关闭开机动画
        difficulty: easy # easy | normal
```

浏览器端通过本插件自己注册的只读路由 `GET /plugins/dsh-boot-duel/config` 读取这两个值；读不到（旧宿主没有该路由）就用同一组默认值，不会因此卡住或报错。

## 出问题会怎样

插件只依赖 `shell.overlay` 插槽、`locale` 服务，以及本包自己的一个只读配置路由。样式表由客户端自己注入（`<style id="dsh-boot-duel-style" data-plugin="dsh-boot-duel">`）；万一注入失败，1.5 秒后检测到样式缺失会直接放行进入首页，而不是留下一条压在对话列表上的黑带。`shell.overlay` 插槽不存在就什么都不渲染并记一条日志；游戏本体抛异常就把你直接放行进入首页。任何情况下都不会把你锁在动画里。

## 卸载

在「插件」页移除该 bundle 并刷新页面，覆盖层彻底消失。插件没有 Host 持久化状态，不写任何文件；唯一注册的是一个只读配置路由，移除插件即随之卸载。

## 兼容性

宿主版本需要提供 `shell.overlay` 浮层插槽（当前 DSH Web 界面具备）。缺少该插槽时插件静默不渲染，不影响应用本身。
