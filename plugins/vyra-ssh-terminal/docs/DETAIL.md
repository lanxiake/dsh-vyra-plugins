# SSH 终端

**一台机器的活，就在这里做完**——左边是连接树，中间是终端，右边能拉开文件、监控和 AI 助手。不用切窗口，也不用把命令结果复制粘贴来复制粘贴去。

## 打开一个连接

侧栏「SSH」→ 点「+ 新建」→ 填主机和用户名 → 连接。已有 `~/.ssh/config` 或 FinalShell 配置的，点「导入」一次带进来。

连上之后，标签页上方有一排工具：

| 按钮 | 作用 |
| --- | --- |
| 文件 | 打开 SFTP 面板：浏览、上传、下载、改名、删、改权限 |
| 监控 | 资源监控（`Ctrl+Shift+M`） |
| AI | AI 助手（`Ctrl+Shift+A`） |
| 历史 | 这条连接敲过的命令（`Ctrl+Shift+H`） |
| 查找 | 终端内查找（`Ctrl+Shift+F`） |
| 日志 | 这条连接的操作与错误 |
| 清屏 / 断开 | 清屏（`Ctrl+Shift+K`）／关闭当前标签（`Ctrl+Shift+W`） |

## 资源监控

连上服务器的标签页会自动开始采样，每 2 秒一次：

- **四张主卡**：CPU（含负载）、内存、Swap、网络（收发双向曲线），外加**磁盘 I/O**读写速率
- **往下可折叠**：GPU、NPU（昇腾）、磁盘分区（含每块盘的读写）、进程榜、网卡明细、延迟
- **预警条**：CPU／内存／磁盘吃紧时在顶部直接说出来，而不是让你自己看曲线

延迟是单独探测的（TCP 握手，30 秒缓存），不会拖慢采样。

## AI 助手

默认就用你在 DSH「设置 → 模型」里选的那个提供商，不用另配 key。

**它和终端是同一台机器。** 你说「看看 /opt 里有什么」，它会在你**看得见的那个终端**里敲命令——所以 `cd` 出来的目录、`export` 的环境变量，对人、对 AI 是同一份。

- **命令打在终端里**：你能看着它跑，也能随时插手中断
- **需要商量的步骤会停下来**：删除、覆盖这类命令会弹卡片，你点「执行」才动
- **输出太长就落盘**：只把首尾给你，完整内容用 `read_output` 按需读
- **能传文件**：`upload` / `download`，下载默认落在 `~/Downloads/dsh-ssh`
- **对话会存下来**：每轮自动落盘（`agent-history.json`），`☰` 里能翻回去接着聊；点历史是**真的恢复上下文**，不是只把文字画出来

### 门禁

命令按 `gate.js` 的规则定级，三档：

- **宽松**（默认）：只拦「危险/破坏性」的（`rm -rf`、单个 `>` 覆盖、`dd of=` 之类）
- **普通**：加上系统级改动（`systemctl`、`apt`、改 `/etc`）
- **严格**：几乎每一步都要确认

定级**只看命令文本**，不听模型的解释——否则提示词里说一句"这是安全的"就绕过去了。

## 文件面板

拖文件进来就上传，**底部有实时进度条**（每条传输的名字、方向、百分比、成功/失败、失败原因）。途中切走标签再回来，进度还在。

行的操作：下载、权限（八进制 644/755/4755）、改名、删除。

## 导出与备份

右键连接可以导出单条、整个文件夹或全部。导出**由 Host 直接写盘**：

- 落在「下载」文件夹（或你指定的绝对路径），文件名带时间戳
- 报告里直接写出**完整保存路径**
- 一个按钮就能**打开所在文件夹并选中那个文件**

可以设口令把密码一起带走；私钥总是内联在文件里。导入时口令跟着走。

## 快捷键

`Ctrl+/` 打开快捷键一览。它分两栏：**本插件接的**，和**交给远端 shell、我们不拦的**——所以你在 bash 里按 `Ctrl+R` 做反向搜索，不会被抢。

## 凭据怎么存

**密码和私钥口令只写进 DSH 的 credentials 服务**，连接档案（`$DSH_HOME/ssh-terminal/connections.json`）里只有主机名和用户名。面板上只显示"有没有设过密码"，不回显。

## 安全边界

- **档案无秘密**：密码/口令与主机信息分开存放
- **命令定级只看文本**：模型不能自我豁免
- **输出净化**：终端输出剥掉控制序列后才进模型上下文
- **导入的备份可以原样再导入**：导出文件就是纯 JSON 备份
- **本插件能连任意可达主机**——按你的凭据权限来

## 已知限制

- 终端用内置 xterm（vendor 里，不联网加载）
- Windows 下本机出口绑定依赖网卡名，部分虚拟网卡不支持
- AI 的「停止」会中止模型请求，但**已经在跑的 SFTP 传输不会被打断**
- 下载走浏览器保存，落点是浏览器下载目录（导出不同，导出是 Host 写盘）
