# 第三方组件

## webm-muxer

- 版本：5.1.4
- 作者：Vanilagy
- 许可证：MIT
- 仓库：https://github.com/Vanilagy/webm-muxer
- 随包文件：`vendor/webm-muxer.js`、`vendor/webm-muxer-LICENSE.txt`

本插件用它把 WebCodecs 编出的 VP9 / Opus 分片封装成单个 `.webm`。
许可证全文见 `vendor/webm-muxer-LICENSE.txt`。

## mp4-muxer

- 版本：5.2.2
- 作者：Vanilagy
- 许可证：MIT
- 仓库：https://github.com/Vanilagy/mp4-muxer
- 随包文件：`vendor/mp4-muxer.js`、`vendor/mp4-muxer-LICENSE.txt`

本插件用它把 WebCodecs 编出的 H.264 / AAC 分片封装成单个 `.mp4`。
许可证全文见 `vendor/mp4-muxer-LICENSE.txt`。
