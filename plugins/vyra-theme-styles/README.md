# vyra-theme-styles · 主题风格

**换主题，不换客户端。** 两套第三方配色，装上就能把整个 DSH 界面换掉。

## 两套配色

| 主题 | 风格 |
|---|---|
| **暖感有机风** | 米色/琥珀色调，圆角更柔，适合长时间阅读 |
| **macOS 毛玻璃** | 冷灰 + 背景模糊，贴近 macOS 原生观感 |

## 用法

设置里切换主题，**立即生效，不用重启**。切回默认也是同一条路径。

## 它做了什么

主题靠覆盖 DSH 客户端自己的主题令牌实现——不是塞一段 CSS 盖住界面，所以列表、输入框、代码块这些既有组件都跟着变，不会出现"一半换了另一半没换"。

## 面板位置

**设置 → 外观 → 主题风格**

## 边界

- 只改**配色与圆角**这类令牌，不改布局；因此不会被上游改版冲掉
- 不改任何行为，纯外观
- 想自己加一套：`themes.js` 里一份令牌表就是一个主题

## 安装

在客户端「设置 → 插件 → 索引源」加入：

```
https://lanxiake.github.io/dsh-vyra-plugins/index.json
```

然后搜索「主题风格」安装。

## 开发

宿主端 `index.js` 只是一个空的挂载行（两套配色都在客户端），`client.js` 里放令牌表并注册到设置区。
